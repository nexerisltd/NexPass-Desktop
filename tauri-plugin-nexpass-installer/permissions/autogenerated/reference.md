## Default Permission

Default permissions for the nexpass-installer plugin

#### This default permission set includes the following:

- `allow-install-apk`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`nexpass-installer:allow-install-apk`

</td>
<td>

Enables the install_apk command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`nexpass-installer:deny-install-apk`

</td>
<td>

Denies the install_apk command without any pre-configured scope.

</td>
</tr>
</table>
